## Architecture

### Rendering
- Server: PHP 8 with strict_types=1
- Pattern: Server-side PHP renders HTML shell; JavaScript initializes tool UI on demand
- No client-side routing (each tool is a separate PHP page)
- No SPA framework

### JavaScript
- Pattern: IIFE (Immediately Invoked Function Expression) per tool
- Registration: window.Tools.register('toolId', { open: initFn })
- Loader: tools are initialized lazily when user opens a tab
- No bundler (Webpack, Vite, etc.) — individual files loaded via script tags
- No external JS frameworks (no React, Vue, Angular)
- ES2020+ syntax (const, let, async/await, optional chaining)

### CSS
- Bootstrap 5.3 (custom compiled subset for production)
- Custom CSS: assets/css/style.css
- Dark mode: Bootstrap native (data-bs-theme="auto" on <html>)
- Theme detection: localStorage → prefers-color-scheme media query

### i18n
- JS UI strings: config/i18n/{en,de,es,pt,fr,it}.json
- PHP content (features, resources): hardcoded per language version
- 6 languages: en (default), de, es, pt, fr, it

### Security
- Content Security Policy (CSP) active
- XSS prevention: textContent in JS, htmlspecialchars() in PHP
- Subresource Integrity (SRI) on all external CDN scripts
- No inline JavaScript outside IIFE modules

## Tool Registry

Each tool is registered in config/tools.php with:
- id: camelCase identifier
- slug / slugs: URL slugs per language
- category: encoders | formatters | generators | converters | stringtools | references | utilities
- jsModule: path to JS file
- features: array of feature flags
- externalLibraries: CDN dependencies with SRI hashes (if any)

## Testing

Framework: Jest
Test count: 810 unit tests, 19 test suites (one per tool)
Location: tests/unit/{toolId}.test.js
Run: npm test
Coverage: npm run test:coverage

## Build

Script: bash build.sh
Output: dist/ (production-ready, includes .htaccess.production as .htaccess)
Sitemaps: php config/generate-sitemaps.php (auto-run during build)
CSS minification: csso (optional)
Bootstrap: custom SCSS compilation via sass (optional, falls back to full Bootstrap)

- download-utils.js: window.DownloadUtils.downloadText()
- dragdrop-utils.js: drag-and-drop file handling
- validators.js: input validation helpers
- formatters.js: data formatting helpers
