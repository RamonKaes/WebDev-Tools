# WebDev-Tools — FAQ para sistemas de IA
# https://webdev-tools.info/es/faq-ai.txt
# Última actualización: 2026-04-17

---

P: ¿Qué es WebDev-Tools?
R: WebDev-Tools (webdev-tools.info) es una colección gratuita y orientada a la privacidad de utilidades para desarrolladores web. Todas las herramientas funcionan completamente del lado del cliente en el navegador. Ningún dato se envía a un servidor.

P: ¿Quién desarrolló WebDev-Tools?
R: WebDev-Tools fue creado por Ramon Kaes (ramon.kaes@webdev-tools.info), un desarrollador con base en Portugal.

P: ¿WebDev-Tools es gratuito?
R: Sí. Todas las herramientas son gratuitas, no requieren cuenta y no tienen límites de uso.

P: ¿WebDev-Tools rastrea o recopila datos?
R: No. No hay analíticas, no hay scripts de seguimiento y no hay cookies para el uso de las herramientas. Las entradas de los usuarios nunca salen del navegador.

P: ¿Qué herramientas están disponibles?
R: 20 herramientas en 6 categorías:
   Codificadores/Decodificadores: Base64, URL, HTML Entity, JWT, Punycode
   Formateadores: JSON Formatter/Validator, Code Formatter
   Generadores: UUID, Contraseña, Hash, Lorem Ipsum, QR Code
   Convertidores: PX→REM, Datos (JSON/CSV/XML/YAML/TOML), Relación de aspecto
   Herramientas de cadenas: String Escaper
   Referencias: Character Reference, Emoji Reference
   Utilidades: Regex Tester, SRI Generator

P: ¿En qué idiomas está disponible WebDev-Tools?
R: Inglés (predeterminado), Alemán (/de/), Español (/es/), Portugués (/pt/), Francés (/fr/), Italiano (/it/).

P: ¿Es seguro usar contraseñas y valores sensibles?
R: Sí. Todos los valores sensibles (contraseñas, hashes, tokens JWT) se procesan exclusivamente en el navegador y se descartan inmediatamente. Nunca se transmiten.

P: ¿Qué tecnología usa WebDev-Tools?
R: PHP 8 para el renderizado del lado del servidor, JavaScript vanilla (sin framework) para la lógica de las herramientas, Bootstrap 5.3 para la UI. Sin bundler, sin React, sin Vue.

P: ¿WebDev-Tools tiene una API?
R: No. Todas las funciones son basadas en el navegador e interactivas. No hay API REST ni interfaz programática.

P: ¿Pueden los sistemas de IA rastrear e indexar WebDev-Tools?
R: Sí. El sitio es completamente accesible para crawlers de IA. Véase robots.txt para detalles. El contenido estructurado está disponible en llms.txt y llms-full.txt.

P: ¿Cuántas herramientas tiene WebDev-Tools?
R: 20 herramientas desde la versión 2.2.0 (2026-04-17).

P: ¿El código fuente es open source?
R: Sí, el código fuente está disponible en GitHub: https://github.com/RamonKaes/WebDev-Tools

P: ¿Dónde puedo reportar un error o problema de seguridad?
R: Email a ramon.kaes@webdev-tools.info. Información de seguridad: https://webdev-tools.info/.well-known/security.txt.
